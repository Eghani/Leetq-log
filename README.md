# Leetq-log

## Description

This is a simple project where I keep my answers to LeetCode problems. LeetCode is a fun website with coding puzzles. These puzzles help you get better at programming. I solve them in C++, which is a programming language. This way, I can look back at my work and learn from it.

## Features

- Solutions to many LeetCode problems
- Organized by how hard the problems are
- Easy to find and run the code
- Helps me practice coding skills

## Folder Structure

- **Easy/**: This folder has problems that are not too tricky. They are good for beginners.
- **Medium/**: Here are problems that are a bit harder. They need more thinking.
- **Hard/**: These are the toughest problems. They take time and smart ideas to solve.
- **LICENSE**: This file tells you how you can use this project.
- **README.md**: This is the file you are reading now. It explains everything.

## How to Run the Project

1. First, make sure you have a C++ compiler. On Windows, you can use g++ from MinGW. On other computers, it might already be there.

2. Open your command line or terminal.

3. Go to the folder with the problem you want. For example, type: `cd Easy`

4. Compile the code. Type: `g++ ValidParentheses.cpp -o ValidParentheses`

   This turns the code into a program you can run.

5. Run the program. Type: `./ValidParentheses` (or `.\ValidParentheses` on Windows)

   You might see some output or need to give input. Check the code for details.

Why do this? Compiling turns your code into something the computer can understand. Running lets you see if it works.
